## Hello there

We're developing VOWLGrapher, a new [VOWL](https://www.semantic-web-journal.net/system/files/swj1114.pdf)-based ontology visualization tool designed with performance, extensibility, and usability in mind.

Previously, we developed WebVOWL Legacy, an improved version of [WebVOWL](https://github.com/VisualDataWeb/WebVOWL), with a notable 514x increase in loading performance compared to the original.
