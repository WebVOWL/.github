## Hello there

We're developing _VOWLGrapher_, a new [VOWL](https://www.semantic-web-journal.net/system/files/swj1114.pdf)-based ontology visualization tool designed with performance, extensibility, and usability in mind.

Previously, we developed _WebVOWL Legacy_, an improved version of [WebVOWL](https://github.com/VisualDataWeb/WebVOWL), with a notable 514x increase in loading speed compared to the original.
